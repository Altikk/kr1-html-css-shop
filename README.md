# «Зерно» — сайт кофейной лавки

Многостраничный HTML/CSS-сайт интернет-магазина кофе свежей обжарки и оборудования для заваривания.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина: шесть связанных страниц, семантическая разметка, единая навигация, якорные ссылки, карточки товаров, таблицы, формы, модальное окно, CSS-переменные, Flexbox, CSS Grid, БЭМ и позиционирование.

## Используемые технологии

- HTML5: семантические теги, формы, `<dialog>`, `<details>`, таблицы;
- CSS3: переменные, Flexbox, Grid, позиционирование, псевдоклассы `:hover`, `:focus-visible`, `:focus-within`, `:user-invalid`, `:has()`, псевдоэлементы, CSS-счётчики;
- методология БЭМ;
- минимальный JavaScript (только модальное окно и валидация форм);
- Git, GitHub, GitHub Pages.

CSS-фреймворки не используются.

## Самостоятельные доработки

1. **Собственная визуальная концепция.** Тематика кофейной лавки, тёплая палитра, шрифты Lora + Manrope, собственные SVG-иллюстрации всех товаров. Контраст всех пар «текст/фон» проверен по WCAG AA (не ниже 4,5:1).
2. **Дополнительная страница** `delivery.html`: шаги оформления заказа с CSS-счётчиками, таблица сравнения доставки, способы оплаты.
3. **Дополнительные блоки на главной:** отзывы, FAQ на `<details>/<summary>` без JavaScript, CTA-блок.
4. **Расширенный каталог:** 9 товаров в трёх категориях, навигация по категориям со счётчиками, sticky-фильтр (категория, обжарка, особенности, цена).
5. **Улучшенные карточки:** бейджи «Хит», «Новинка», «−15%», категория, характеристики, старая цена, модификаторы `--discount`, `--featured`, `--out-of-stock` (неактивная кнопка «Нет в наличии»).
6. **Подробная карточка товара:** превью-галерея, ноты вкуса, наличие и дата обжарки, две таблицы, внутренние якоря, блок «С этим покупают».
7. **Сценарий заявки:** быстрый заказ в модалке подставляет выбранный товар; полная форма с выбором помола и способа получения (радиокнопки-«плашки», выбранная подсвечивается через `:has()`); подсветка ошибок; сообщения об успешной отправке.
8. **Доступность:** ссылка «Перейти к содержимому», видимый фокус у всех интерактивных элементов, `aria-current`, `aria-describedby` для подсказок, `aria-invalid`, `role="status"` у уведомлений, `alt` у изображений, `scroll-padding-top`, чтобы якоря не прятались под шапкой, учёт `prefers-reduced-motion`.
9. **Кнопка «Наверх»** на `position: fixed`, работает без JavaScript (ссылка на `#top`).
10. **Порядок в CSS:** файл разбит на 21 пронумерованный раздел, z-index вынесены в переменные, стилизация только по классам, а не по `id`.
11. **Минимальная адаптация** (одна колонка на узких экранах). Полная адаптивность будет в КР №3.
